# 워치리스트 알림 데스크

엑셀로 정리한 관심 종목(8개 열, 약 100종목)의 뉴스를 모으고, 뉴스에 따라 **매수 관심 / 관망 / 회피** 시그널을 매기는 페이지입니다.
평일 하루 8회 Claude가 새 뉴스를 찾아 페이지를 갱신하고, 요약을 휴대폰 푸시 알림으로 보냅니다.

- 페이지: https://claude.ai/artifact/DeYaAasm5hi1mAxVR9Sqeh
- 목표: 2026-09-25 ~ 2026-11-25, 100만원 → 300만원 (+200%, 거래일당 약 +2.65% 복리)

## 알림 일정 (평일)

| 한국 시간 | 슬롯 | 기준 |
|---|---|---|
| 07:50 | 미국 마감 정리 | 서울 |
| 11:50 | 국내 장중 | 서울 |
| 15:50 | 국내 마감 | 서울 |
| 19:50 | 미국 개장 전 | 서울 |
| 22:40 (11/2부터 23:40) | 미국 개장 직후 | 뉴욕 09:40 |
| 00:40 (01:40) | 미국 장중반 | 뉴욕 11:40 |
| 02:40 (03:40) | 미국 장후반 | 뉴욕 13:40 |
| 04:40 (05:40) | 미국 마감 직전 | 뉴욕 15:40 |

미국 장중 4회는 뉴욕 시간 기준이라 서머타임이 끝나면(11/1) 한국 시간으로 1시간씩 늦어집니다.
토요일 08:50에는 한 주를 돌아보는 주간 복기 알림이 한 번 더 옵니다.

알림 첫 줄에 등급이 붙습니다.
- **긴급**: 보유 종목이 손절선·익절선에 닿았거나 3% 이내로 다가옴, ±7% 이상 급변
- **중요**: 시그널 변경, 진입 조건 충족, 오늘 할 일 변경
- **정보**: 그 외 (변화가 없으면 3줄 이내로 짧게)

환율(원/달러, 원/100엔, 엔/달러, 달러 인덱스)은 알림마다 갱신됩니다. 페이지의 '환율 알림 조건'에
목표 환율이나 하루 변동률을 넣어 두면, 조건에 닿을 때 원인과 함께 [중요] 푸시가 옵니다(조건마다 하루 한 번).
'미국 마감 정리'와 '국내 마감' 알림에는 조건과 관계없이 환율 한 줄이 붙습니다.

**앤트로픽 IPO 워치**: 알림마다 상장 진행 상황(증권신고서 공개 → 로드쇼 → 공모가 범위 → 공모가 확정 → 상장)을 확인합니다.
단계가 올라가면 [중요], 거래가 시작되면 [긴급] 푸시가 옵니다. 공시·회사 발표로 확인된 단계만 올리고, 보도는 '미확정'으로 표시합니다.
이 데스크를 운영하는 Claude는 앤트로픽이 만든 모델이라, 앤트로픽은 사실만 전하고 매수 시그널은 내지 않습니다.

## 페이지 사용법

1. **오늘 할 일**: 알림이 다음 거래일에 할 행동을 3~6개로 정리합니다. 한 일은 체크하세요.
2. **다가오는 일정**: 2주 안의 실적 발표·경제지표·휴장일을 D-day로 보여줍니다.
3. **내 보유 종목**: 산 종목의 매수가·수량을 기록하면, 알림마다 현재가를 갱신하고 손절·익절선을 지켜봅니다. 팔면 '매도 기록'을 누르세요.
4. **환율**: 4가지 환율과 원인, 최근 추이, 알림 조건 설정.
5. **뉴스 시그널**: 매수 관심·관망·회피와 시그널 이후 수익률.
6. **복기**: 시그널 적중률, 실현 손익, 자동 손절 설정률, 규칙대로 매도한 비율, 매매일지.

## 구성

- `desk/index.html` — 데스크 페이지 소스 (Artifact로 게시됨)
- `desk/routine-prompt.md` — 알림 루틴 3개(미국 장중 4회, 장 사이 4회, 토요일 주간 복기)가 매번 실행하는 지시문
- `data/watchlist.csv` — 원본 엑셀을 옮긴 워치리스트
- `data/seed_2026-09-25.py` — 첫날 넣은 뉴스 14건과 시그널 데이터

페이지 데이터(뉴스, 시그널, 알림 기록, 평가금액)는 Artifact 데이터베이스에 있습니다.
컬렉션: `news`, `picks`, `alerts`, `events`, `positions`, `signalLog`, `checks/<날짜>`,
`fxHistory`, `fxAlerts/settings`, `fxAlerts/state`,
`meta/market`, `meta/plan`, `meta/status`, `meta/today`, `meta/fx`, `portfolio/main`.

## 주의

투자자문이 아닙니다. 시그널은 공개 뉴스에 대한 해석이며 틀릴 수 있습니다.
2개월 3배는 전문 운용역도 거의 달성하지 못하는 수익률입니다. 페이지의 운용 규칙(종목당 30% 상한, 현금 20%, 손절선, 레버리지 금지)을 먼저 지키세요.
